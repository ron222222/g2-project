本次仅添加注释，没有修改运行逻辑。逐行注释用【原第N行】标识，方便和原文件对照。

## 1. 如何阅读
先搜索 def main():，理解总流程；遇到函数调用再搜索 def 函数名。函数定义时不立即执行函数体，main调用后才执行。缩进决定if、for、try内部范围。#后面是注释，不执行。

## 2. 总调用链
main → 启动检查 → HOME/WP1/WP2 → detect_product → detect_product_batch → 高度规划 → 等价长轴选择 → XY粗对准 → 固定锚点姿态 → XY精修 → PreGrasp → 打开 → Grasp → 闭合 → 抬升 → 腰部右转 → 释放 → 腰部返回 → WP2 → WP1 → 下一轮。

## 3. 本附件的真实参数
循环次数10；固定产品高度40mm；TCP相对产品顶部偏移-23mm；桌面TCP名义下限10mm；PreGrasp顶部上方120mm；腰部-80度，每段最多40度；姿态每大段最多12度。所有数值保持原样。

## 4. 高度公式
产品顶部Z = 锁定桌面Z + 0.040
名义抓取Z = 产品顶部Z - 0.023
最终抓取Z = max(名义抓取Z, 锁定桌面Z + 0.010)
因此当前名义目标是桌面Z + 0.017米。TCP目标不等于实际指尖最低点；还受工具几何、姿态、实际跟踪误差影响。

## 5. 稳定门控
单批最多采8个位置，至少4个位置、3个角度才形成有效结果；外层要求3个有效批次，单批Z极差不超过15mm，批次XY标准差不超过5mm，长轴相对首批角差不超过6度。无有效检测时清空批次。外层120秒并非严格总时限，单批阻塞可能延长实际等待。
